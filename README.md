# Number Viewer on X

X（旧Twitter）上で省略されて表示される「いいね数」（例: 1.2万, 1.5K など）を、正確な数値（例: 12,345）で詳細表示するChrome拡張機能です。

## インストール方法

Chromeウェブストアには公開されていないため、デベロッパーモードを使用して手動でインストールする必要があります。

1. このリポジトリ（フォルダ）をご利用のPCにダウンロードまたはクローンし、展開します。
2. Google Chromeを開き、URLバーに `chrome://extensions/` と入力して拡張機能管理ページを開きます。
3. 画面右上の 「デベロッパーモード」 のスイッチをオンにします。
4. 左上に表示される 「パッケージ化されていない拡張機能を読み込む」 ボタンをクリックします。
5. ダウンロードして展開した本拡張機能のフォルダを選択します。

## 使い方

1. インストール完了後、X ([https://x.com](https://x.com)) を開きます。
2. 各ツイートの「いいね数」が詳細な数値になっていることを確認してください。
3. ブラウザの右上にある拡張機能アイコン（パズルマーク）から「Number Viewer on X」をクリックしてポップアップを開くと、機能のON/OFFを切り替えるスイッチが表示されます。
   ※スイッチを切り替えた際、反映されない場合はページを再読み込み（リロード）してください。

## 注意事項

* X（Twitter）の仕様変更やUIのアップデートにより、本拡張機能が正常に動作しなくなる可能性があります。
